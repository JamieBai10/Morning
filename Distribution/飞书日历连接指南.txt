Morning 飞书日历连接指南

Morning 可以通过飞书官方 CLI 读取你授权账号的飞书主日历，生成「昨日回声」。这是目前的初步连接方式：首次设置需要使用 Mac 的终端。如果你暂时不需要飞书日历，可以跳过；Morning 的其他功能仍可使用。

一、安装飞书 CLI

1. 确认 Mac 已安装 Node.js（它提供 npm 和 npx）。如果没有，请前往 Node.js 官方网站 https://nodejs.org/ 按说明安装。
2. 打开「访达」→「应用程序」→「实用工具」→「终端」。
3. 复制以下命令，粘贴到终端，按回车，按提示完成飞书官方 CLI 的安装：

   npx @larksuite/cli@latest install

4. 安装完成后，关闭并重新打开终端，输入以下命令，确认能够看到版本号：

   lark-cli --version

飞书 CLI 的官方安装说明与最新要求：
https://github.com/larksuite/cli/blob/main/README.zh.md

二、配置飞书 CLI

如果此前已配置过飞书 CLI，可以跳到下一步。否则在终端输入：

   lark-cli config init

根据终端和飞书页面的引导配置应用。飞书组织可能要求管理员审核或批准；请查看页面提示。如果已有 CLI 配置，请留意配置过程的选项，避免意外覆盖现有配置。不要将 App Secret、验证码或访问令牌发给别人。

三、授权读取日历

在终端输入：

   lark-cli auth login --scope 'calendar:calendar.event:read'

根据提示打开飞书授权页面，并核对实际显示的权限后决定是否授权。Morning 查询日历时使用用户身份和只读日程查询；CLI 已有的其他授权不会因此自动撤销。如果登录失效，可重新执行此步骤。

四、在 Morning 中启用

1. 打开 Morning，点击屏幕顶部菜单栏中的 Morning → Settings（设置）。
2. 打开「数据来源」，点击「连接飞书…」。
3. 点击「检查授权并启用」。如果检测通过，飞书日历开关会打开。
4. 打开「昨日回声」；它会在读取后更新。仅检测到本机授权不代表网络、组织策略或日历数据一定可用。

五、常见问题

- 提示找不到 lark-cli：重新打开终端检查版本；目前 Morning 在 /opt/homebrew/bin、/usr/local/bin 和 ~/.local/bin 查找 CLI。若实际安装在其他目录，Morning 暂时无法识别。
- 无法授权或显示需要审批：联系飞书组织管理员确认应用和日历读取权限。
- 已连接却没有日程：目前只读取飞书主日历，其他共享或订阅日历暂不支持；确认要查看的是昨天的日程，以及网络和飞书账号是否正确。
- 同一日程也同步到苹果日历时，Morning 会尝试按标题与时间去重，但不同来源的标题或时间有差异时仍可能重复。
- 不再使用：在 Morning「数据来源」里关闭飞书日历即可停止通过 Morning 读取；这不会撤销 CLI 本身的授权。撤销授权请参考飞书或 CLI 的官方说明。
